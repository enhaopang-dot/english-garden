# 记忆宫殿 · 英文单词学习页 · English Garden

> 一个纯 HTML 的单页单词学习应用。每个词配英文释义、中文谐音、记忆宫殿场景图和例句。改一个 JSON 就加词，不用登录、不用装 App、双击就开。

**关键词**：英语学习 · 背单词 · 记忆宫殿 · 联想记忆 · 单词卡片 · 单页应用 · 纯前端 · 无后端 · 离线可用 · HTML · 英语词汇 · memory palace · vocabulary builder · flashcards · single page app

---

## 这是什么

一个用「记忆宫殿法」背单词的单页应用。

每个词有六层信息：

1. **英文单词**与音标
2. **英文释义**（用英文理解英文，不靠中文翻译）
3. **中文谐音**（记得住的发音锚点）
4. **记忆宫殿场景**（一张图 + 一段画面描述）
5. **例句**
6. **联想链**（和已知词挂钩）

## 为什么这么做

传统背单词 App 的问题是：**词表和大脑之间没有钩子**。看到单词想起中文翻译，隔天就忘。

记忆宫殿法把抽象字母变成具体画面，靠空间的、视觉的记忆来挂词。成本是准备时间，收益是记住之后不容易塌。

## 用法

直接用浏览器打开 `index.html`。

加新词：编辑 `words.json`，跑一次同步脚本：

```bash
python scripts/sync.py
```

生成新词的配图：

```bash
python scripts/batch_images.py
python scripts/compress_images.py
```

## 目录

```
├── index.html          单页应用，自带样式与交互
├── words.json          词库（英文释义 / 谐音 / 宫殿场景 / 例句）
├── images/             每个词的记忆场景图（jpg / png / webp）
└── scripts/            同步、批量生图、压缩
```

## 设计取舍

- **纯前端**：没有后端、没有账号、没有云同步。数据就是你电脑上的一个 JSON。
- **离线可用**：断网也能背，适合通勤。
- **图片三格式**：jpg 给兼容性、webp 给体积、png 给透明。

## 自带示例

仓库内 `words.json` 附 12 个示例词，可以直接跑起来看效果，再换成自己的。
